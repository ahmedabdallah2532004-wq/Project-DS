# Access Analytics Service

PM3 microservice running on port `3007`.

## Endpoints

- `GET /health`
- `GET /ready`
- `GET /metrics`
- `GET /docs`
- `GET /api-docs`
- `POST /api/access-analytics-service/process`

## Commands

```bash
npm install
npm run lint
npm test
npm run test:coverage
npm start
```
